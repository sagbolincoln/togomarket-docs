🌍 Vision

Pourquoi TogoMarket ?

Le commerce en ligne au Togo manque d'une plateforme marketplace locale. Les ventes se font principalement via WhatsApp et Facebook, sans outil dedie.

🚩

Probleme

Pas de marketplace locale au Togo. Les vendeurs utilisent les reseaux sociaux, sans gestion de stock, paiement securise, ni suivi de commande.

💡

Solution

TogoMarket : plateforme mobile-first avec paiement Stripe, multi-vendeurs, gestion de stock, et systeme de livraison securise par code 6 chiffres.

🎯

Marche cible

Vendeurs togolais (electronique, mode, maison) et acheteurs urbains. Extension prevue en Afrique de l'Ouest (FCFA zone UEMOA).

⚡ Fonctionnalites

Fonctionnalites cles

Les fonctionnalites qui differencient TogoMarket des solutions existantes.

🛒

Panier multi-vendeurs

L'acheteur remplit 1 seul panier avec des produits de differents vendeurs. Au checkout, le systeme cree automatiquement 1 commande par vendeur avec 1 seul paiement.

🔒

Code de livraison securise

Un code a 6 chiffres est genere automatiquement a l'expedition. L'acheteur le communique au livreur pour confirmer la reception. Anti-fraude integre.

💰

Paiements multiples

Stripe (cartes bancaires) + TMoney (Togocom) + Flooz (Moov Africa). Les paiements Mobile Money couvrent 60%+ de la population togolaise. Confirmation automatique par webhook/callback.

🎨

Variantes produit

Chaque produit peut avoir des couleurs (palette visuelle) et des tailles (vetements XS-XXL, chaussures 36-45). Selection obligatoire avant ajout au panier.

📍

Geolocalisation GPS

Detection automatique de la position de l'acheteur avec remplissage auto des champs d'adresse via reverse geocoding. Adresses multiples.

📱

Mobile-first

Application React Native / Expo deployable sur Android et iOS. Theme clair/sombre, animations fluides, pull-to-refresh, design moderne.

👥 Acteurs

4 roles, 1 hierarchie

Un systeme de roles avec heritage : l'admin peut tout faire, le vendeur peut aussi acheter.

Hierarchie des roles et permissions

ROLE_ADMIN herite de ROLE_SELLER qui herite de ROLE_BUYER. Chaque niveau ajoute des permissions specifiques.

🔄 Processus

Flux de commande

Du panier a la livraison confirmee : 4 phases, 100% tracable.

Processus complet de commande

Phase 1 : Achat (panier + Stripe) → Phase 2 : Paiement (webhook) → Phase 3 : Preparation (vendeur) → Phase 4 : Livraison (code securise).

Commande multi-vendeurs

Sophie achete un iPhone chez Kofi et une robe chez Ama. 1 seul paiement, 2 commandes independantes, 2 livraisons avec codes differents.

🔒 Innovation

Code de livraison securise

Notre systeme anti-fraude unique : un code a 6 chiffres garantit que seul le veritable destinataire confirme la reception.

Processus en 4 etapes

Generation automatique, visible uniquement par l'acheteur, communication orale au livreur, verification serveur avec suppression apres validation.

🌐 Plateformes

3 interfaces, 1 experience unifiee

TogoMarket est accessible sur mobile (Android/iOS), sur le web, et via une API ouverte. Toutes les plateformes partagent le meme backend et les memes donnees en temps reel.

📱

Application Mobile

React Native / Expo, deployable sur Android et iOS. Theme clair/sombre, animations fluides, geolocalisation, camera pour upload de photos produits.

ECRANS PRINCIPAUX
Accueil • Catalogue • Detail produit • Panier • Checkout • Commandes • Profil • Dashboard vendeur • Gestion produits • Boutique vendeur
🖥

Application Web

React 18 + TypeScript + Vite + Tailwind CSS v4. Interface responsive pour la gestion avancee, l'administration et la navigation depuis un ordinateur.

MODULES WEB
Catalogue public • Authentification • Espace acheteur • Espace vendeur • Dashboard admin • Gestion categories • Validation vendeurs
⚙

API Backend

Symfony 7 + API Platform 4. API RESTful JSON-LD avec documentation Swagger auto-generee. Authentification JWT, webhooks Stripe, filtrage avance.

ENDPOINTS CLES
